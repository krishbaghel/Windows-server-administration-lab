# Windows Server Administration Lab

## Project Overview

This project demonstrates practical Windows Server administration and IT infrastructure management in a lab environment.

The lab includes Windows Server configuration, Active Directory, DNS, DHCP, Group Policy, file sharing, department-based permissions, IIS and testing verification.

## Technologies and Skills

- Windows Server
- Active Directory Domain Services (AD DS)
- Active Directory Users and Computers
- DNS
- DHCP
- Group Policy (GPO)
- USB Storage Blocking
- File and Folder Sharing
- NTFS and Share Permissions
- IIS Web Server
- Basic Network Administration
- System Administration and Troubleshooting

## Project Objectives

- Configure Windows Server.
- Configure Active Directory Domain Services.
- Create and manage users and computers.
- Configure DNS and DHCP services.
- Create and apply Group Policy.
- Block USB storage devices using Group Policy.
- Configure file and folder sharing.
- Configure HR and IT department permissions.
- Install and configure IIS.
- Test and verify the configured services.

## Lab Implementation

### 1. Windows Server Setup
Initial Windows Server installation and configuration.

### 2. Active Directory
Configured Active Directory Domain Services for centralized user and computer management.

### 3. AD Users and Computers
Created and managed users, groups and computer objects.

### 4. DNS
Configured DNS for domain name resolution.

### 5. DHCP
Configured DHCP to provide automatic IP configuration to client systems.

### 6. Group Policy - USB Block
Created and applied a Group Policy to restrict USB storage devices.

### 7. File Sharing
Configured shared folders on the Windows Server.

### 8. HR File Permissions
Configured access permissions for the HR department shared folder.

### 9. IT File Permissions
Configured access permissions for the IT department shared folder.

### 10. IIS
Installed and configured Internet Information Services (IIS) as a web server.

### 11-13. Testing and Verification
Performed testing to verify:

- Active Directory
- DNS
- DHCP
- Group Policy
- USB blocking
- File sharing
- HR permissions
- IT permissions
- IIS accessibility
