# Windows Server Administration Lab

## About This Project

This project demonstrates basic Windows Server administration skills in a lab environment.

## Technologies and Skills

- Windows Server
- Active Directory Domain Services (AD DS)
- DNS
- Group Policy (GPO)
- User and Group Management
- File and Folder Permissions
- Basic Network Administration

## Project Objectives

- Configure Windows Server
- Create and manage Active Directory users and groups
- Configure basic DNS services
- Create and apply basic Group Policies
- Practice file and folder permissions
- Perform basic system administration and troubleshooting

## Learning Outcome

This project helped me develop practical knowledge of Windows Server administration, Active Directory, networking, and basic IT infrastructure security.
